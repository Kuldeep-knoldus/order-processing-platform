# Employee Management Console Application

A Java 21 console application for managing employees. It demonstrates Java fundamentals, encapsulation, classes and objects, collections, exception handling, and Stream API filtering.

## Requirements covered

- Add and display employees
- Search by employee ID
- Filter by department
- Find active employees above a salary threshold
- Custom `EmployeeNotFoundException`
- `Map` storage and Stream API filtering
- Input validation and duplicate-ID handling

## Run

From this directory:

```powershell
mvn test
mvn compile
java -cp target/classes com.nashtech.EmployeeManagementApplication
```

The application starts with the employees from the assignment example. Select option `6` to exit.
